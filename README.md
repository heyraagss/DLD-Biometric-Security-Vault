# DLD Biometric Security Vault

## Project Overview
A Digital Logic Design project developed using Tinkercad Circuits to demonstrate digital logic and input-based access control.

## Components Used
- DIP switches
- Logic gates
- LEDs
- Buzzer
- Resistors

## Working Principle
The circuit processes switch inputs using digital logic gates. The output indicators respond to the input combination, and the buzzer provides an alert.

## Tools
- Tinkercad Circuits
- Digital Logic Design
